# 怀孕初期hcg低不要怕，有什么方法可以快速提高？

> 更新时间：2026-09-11 (UTC+8)

我是上月16号来月经的，平时一般都是推迟几天的，偶尔准时，这个月22号晚上测出来是阴性，24号早上测出来显示怀孕了，25号去医院抽血，测出来雌二醇是1069，孕酮是79，血HCG只有571，很低，医生说不要怕，请问怀孕初期hcg低为什么医生说不要怕？有什么方法可以快速提高？
孕早期HCG低可能是黄体功能不全、胚胎质量低或宫外孕等导致的，如检查发现hcg数值很低或者增长缓慢千万不要太担心了，而是应该尽量放松精神状态，可以通过注意休息，补充充足营养、使用药物及手术等进行治疗，也可以多吃一些含有大豆异黄酮的黄豆和豆制品，能起到非常好的调节内分泌的作用。

怀孕之后HCG和孕酮是维持孕囊生长发育的两项重要指标，如果孕酮在正常范围值之内，而且做B超又能够确定宫内孕，可以在医生指导下肌肉注射人绒毛膜促性腺激素，有利于HCG数值上升，有利于孕囊的生长发育，如果孕酮数值偏低或者或者孕囊没有在宫腔内着床，需要医生根据原因对因对症处理。

- 多休息：怀孕早期HCG值低会引起流产，导致出现阴道流血的情况。怀孕早期HCG低要增加睡眠时间，多休息，减少运动，保持良好的情绪，避免激动；
- 药物治疗：可以通过口服或者肌肉注射黄体酮来提高HCG值。但是需要到医院进行检查，遵医嘱进行药物治疗；
- 食疗：一些食物可以起到辅助作用，如大豆类食品。同时注意多补充体内所需的维生素C和维生素E，也会起到补充孕酮的辅助作用。
建议孕妇一旦发现自己孕早期HCG数值低以后，及时就医完善相关检查，规范治疗，另外，药物可能会引起一定的副作用症状，应在医生指导下使用，不要盲目用药。
